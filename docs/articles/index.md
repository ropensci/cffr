# Articles

### Guides

Get started creating and maintaining CFF metadata.

- [Manipulating citations with
  cffr](https://docs.ropensci.org/cffr/articles/cffr.md):

  Learn how to modify `cff` objects.

### Crosswalks

Technical mappings between R, CFF and BibTeX metadata.

- [From R to CFF](https://docs.ropensci.org/cffr/articles/r-cff.md):

  A comprehensive description of the internal mappings performed by
  **cffr**.

- [BibTeX and
  CFF](https://docs.ropensci.org/cffr/articles/bibtex-cff.md):

  This article presents a crosswalk between BibTeX and the Citation File
  Format, as implemented by the **cffr** package.
